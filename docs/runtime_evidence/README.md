# AeroRamp runtime evidence

These artifacts were generated by running the actual AeroRamp `motion` pipeline over the committed public DVIDS sample:

```powershell
$env:PYTHONPATH = "apps/api;packages/sdk/python"
py -3.12 scripts/generate_runtime_evidence.py
```

The run decodes the public MP4, samples it at 4 FPS, applies the OpenCV MOG2 motion detector, tracks detected regions, and writes the annotated MP4 and compressed observations through `aeroramp.vision.pipeline.process_video`. The CSV trace and summary are derived from those emitted observations.

- `aeroramp-dvids-motion-runtime.mp4`: real sampled-frame annotation video.
- `aeroramp-dvids-motion-runtime-poster.jpg`: decoded poster frame from that MP4.
- `aeroramp-dvids-motion-track-trace.csv`: per-frame track observations.
- `aeroramp-dvids-motion-observations.json.gz`: compressed pipeline observations.
- `aeroramp-dvids-motion-runtime-summary.json`: source/model boundary, measured counts, and artifact hashes.

The runtime deliberately reports generic `moving_object` detections. It is not an airport-specific detector or certification benchmark; the summary records that limitation explicitly.
